# 用量页对账、坐标与账户同宽

日期：2026-09-17  
状态：已认可  
前置：`2026-09-16-usage-overview-agnes-design.md`、生产 SQLite unixepoch 修复  
范围：用量明细全量 + 导出并对齐总览；趋势补齐坐标；活跃度月份横坐标并铺满卡片；账户卡片与用量同宽。

本文覆盖并修订前序规格中的这些条目：明细与趋势共用窗口、无导出、年历窄屏横向滚动不压格子、账户 `max-w-3xl`。口径、三套窗口（总览累计 / 年历 6 个月 / 趋势 7d·30d·month）、净消耗与生成次数定义不变。

## 背景

走测后四类问题：

1. 明细跟趋势共用 `7d|30d|month`，且过滤 `generationCount === 0`，表加总对不上五卡。
2. 趋势折线没有可见的横纵坐标。
3. 活跃度没有月份横坐标，格子固定 `12px` 靠左一簇。
4. 账户卡片仍 `max-w-3xl`，用量已是 `max-w-6xl`。

## 已锁定决策

| 项 | 选择 |
|----|------|
| 明细窗口 | 账户全部历史，与趋势窗口独立 |
| 明细行 | 活动日稀疏：`generationCount > 0` 或 `netConsumed > 0` 才出一行；不铺空日历 |
| 表底合计 | 直接用总览口径，不对逐日净消耗二次加总（跨日退款时行之和可以小于累计） |
| 导出 | 客户端 UTF-8 BOM CSV，列与表头一致，含合计行；不含展开流水 |
| 趋势 | 仍为近 7 天 / 30 天 / 本月；只补坐标与边距 |
| 年历 | 周列上方标月份；格子均分铺满卡片宽度，保持接近正方形 |
| 账户 | 去掉 `max-w-3xl`，与用量同吃 `max-w-6xl`；三卡仍纵向、内容左对齐 |

非目标：流水级导出、自定义日期、趋势改成全历史、年历点击、改五卡口径、改 MembershipModal。

---

## §1 用量明细

`GET /membership/usage-days?range=all`：

- `from` = Unix epoch 对应的上海日历日，`to` = 今天
- `days` = `foldDailyUsage` 的稀疏结果，**不** `fillCalendarDays`
- 非法 `range` 仍回落 `7d`；`all` 合法

用量 Tab 并行拉：总览一次、趋势 `usage-days(当前 range)`、明细 `usage-days('all')`。切 7d/30d/month **只刷新趋势**，不重拉明细。

表：

- 列不变：日期、生成次数、积分消耗、文本、图片、音频、视频
- 日期新→旧
- 行展开流水逻辑不变
- 表底「合计」：生成次数 / 积分消耗 / 文本 / 图片 / 音频 / 视频 = `overview.generationCount` / `overview.netConsumedTotal` / `overview.byCategory.*`
- 「累计活跃」仍只在五卡和年历，不进表底

导出：

- 按钮文案「导出 CSV」，无数据时禁用
- 文件名 `lnkpi-usage-YYYY-MM-DD.csv`（上海今天）
- 首行 BOM + 表头；随后活动日行；末行「合计」与表底相同数字
- 积分消耗列含 other（与表一致）

## §2 用量趋势坐标

SVG 绘图区四周留白：左 Y 刻度、下 X 刻度、上/右避免贴边。淡水平网格。点 hover 仍用 SVG `<title>`。

| 轴 | 规则 |
|----|------|
| Y | `0`、中间值、当前序列最大值；整数；左对齐刻度 |
| X · 近 7 天 | 每天 `M/D` |
| X · 近 30 天 | 约每 5 个点一个刻度，含首末日 |
| X · 本月 | 约每 4～5 天一个刻度，含首末日 |

## §3 活跃度

- 每个周列上方：该列第一个窗口内日期相对上一列换月时写 `M月`；跨年或首个标签写 `YYYY年M月`
- 格子 `1fr` 均分卡片内容宽，`aspect-square`，不再固定 `h-3 w-3`
- 左侧仍标周一/周三/周五；hover、分档绿、不可点击不变

## §4 账户同宽

个人中心根仍 `mx-auto max-w-6xl`。账户三张卡去掉内层 `max-w-3xl`，与用量区块同宽。不改成三列，不把按钮做成通栏巨按钮。

## 成功标准

- 明细合计四项（生成次数、积分消耗、图片、视频）与五卡一致；文本/音频与总览 `byCategory` 一致
- 导出 CSV 打开后行数 = 活动日 + 表头 + 合计
- 趋势三种窗口都能读到 Y 数值和 X 日期
- 活跃度能读到月份，格子铺满卡片内容宽
- 账户与用量卡片左右边缘对齐
