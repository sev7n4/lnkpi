## 二、用户旅程总览（验收检查表）

按时间顺序，用户在一次完整任务中应经历：

| 序号 | 用户阶段 | 用户看到什么 | 用户做什么 | 通过标准（摘要） |
|------|----------|--------------|------------|------------------|
| 1 | 准入 | 识图 QA 提示（若需要） | 选「重拍」或「生成白底图」 | 理由 **可读**；非纯技术 JSON |
| 2 | 方案初稿 | 侧栏 **长文行业方案** | 阅读 | **对话框 prose**，画布 **无** 方案节点 |
| 3 | 宏观选择 | A/B/C **卡片** + 推荐标签 | 勾选 1~2 套；确认 | 单套时 **无** 卡片打断 |
| 4 | SSOT 落盘 | 画布出现 **方案文本节点** | 可点开阅读/编辑 | 内容为 **选定 prose**，非 JSON |
| 5 | 构图拆解 | 侧栏 **shot 列表**；画布构图组（可折叠） | 确认或删减 shot | 类型覆盖 utterance 点名场景 |
| 6 | 拓扑确认 | 拓扑预览 / mermaid | 「确认出图」 | 未确认前 **不** 自动出图 |
| 7 | 出图等待 | 进度「节点出图中…」 | 等待 | 勿切标签；可部分失败提示 |
| 8 | 定稿交付 | 按 shot 分组候选图 | 切换候选 / 微调 / **确认全部定稿** | 每场景最终 1 张 |

## 三、经典场景 UAT（CVS 用户路径）

### UAT-CVS-02 — 大闸蟹包装（P0 必过）

**角色：** 电商运营，中秋礼盒包装需求  
**话术：**

> 这是我们中秋要卖的大闸蟹，帮我设计礼盒和快递运输包装视觉，要保鲜防损。出包装效果图、冷链/缓冲结构示意，再加一张模特手持礼盒的送礼效果图，要有中秋节日氛围。

**附件：** 大闸蟹实拍（资产库「大闸蟹实拍」或等价 product 图）

#### 步骤与预期

| Step | 用户操作 | 预期（用户可见） | UAT-ID |
|------|----------|------------------|--------|
| 1 | 新建画布 → 新建对话 → 选技能 → 选附件 I1 → 发送话术 | Agent 开始执行 | UAT-CVS-02-001 |
| 2 | 若出现 QA 门控 | 文案说明 **识图结论**（如清晰度/是否白底/产品识别）；可选「生成白底图」 | UAT-CVS-02-002 |
| 3 | 等待 Phase 2a | 侧栏出现 **完整包装方案正文**（冷链、礼盒、中秋元素等），**不是** JSON 块 | UAT-CVS-02-003 |
| 4 | 若有多套宏观方案 | 卡片展示 **方案 A/B/C**（或等价标签），**至少一套带「推荐」及理由** | UAT-CVS-02-004 |
| 5 | 勾选 **一套** 方案 → 确认 | **此步骤之前画布无方案节点** | UAT-CVS-02-005 |
| 6 | 确认后看画布 | 出现 **方案文本节点**，正文为所选方向 prose，**人类可读** | UAT-CVS-02-006 |
| 7 | 等待拆解 | 侧栏或门控展示 **≥3 个 shot**：包装主视觉、结构示意、模特手持（名称可中文） | UAT-CVS-02-007 |
| 8 | 确认 shot / 拓扑 → 确认出图 | 白底/四视图 **在 SSOT 之后** 再生成（lazy）；节点陆续出图 | UAT-CVS-02-008 |
| 9 | 定稿门控 | 按 **场景/shot** 切换候选；「确认全部定稿」可用 | UAT-CVS-02-009 |
| 10 | 对照 utterance | 最终交付覆盖：**包装效果图 + 结构示意 + 模特送礼**（允许部分出图失败但需明确提示） | UAT-CVS-02-010 |

**❌ 常见 Fail 现象（记录即 Fail）：**

- 侧栏只出现 JSON / `visual_intent` 字段，无行业长文  
- 未确认方案前画布已有方案 JSON 节点  
- Plan 只拆 **1 类** 图（仅白底主图），无包装/模特  
- SSE 立即断开（多为 `demo-*` 画布未落库）  
- 定稿门控从未出现

### UAT-CVS-02-AB — 大闸蟹 A+B 两套都要（P1）

**话术追加：** 「红金礼盒和极简牛皮两套方案我都要出图。」

| Step | 预期 |
|------|------|
| 1 | 宏观卡片可 **多选 2 套**（第 3 套应被阻止或提示） |
| 2 | SSOT 节点内分 **「方案 A」「方案 B」** 两节（或清晰分节标题） |
| 3 | shot 列表中 **A、B 各自** 有包装/模特类 shot（重叠场景 **两张都出**，不合并成一张） |
| 4 | 定稿后交付张数 = 两套 shot 之和（每 shot 定稿 1 张） |

### UAT-CVS-01 — 保温杯电商全套（P0）

**话术：**

> 这是我们要上架的保温杯，帮我出一套电商推广图：天猫主图、详情图、模特展示图、模特手持使用的效果图、卖点图、推广海报。风格简约高级，强调316不锈钢和12小时保温。

**附件：** 保温杯 product 实拍

| 检查项 | 预期 |
|--------|------|
| 方案 prose | 含 listing / 卖点 / 风格描述 |
| **不应出现** | 用户未提的 **包装类** shot |
| shot 覆盖 | 主图、详情、模特、手持、卖点、海报 **六类**（或 utterance 等价拆分） |
| 定稿 | 每类场景至少 1 张可定稿 |

---

### UAT-CVS-03 — 客厅空间（P0）

**话术：**

> 这是待装修客厅，出有人在里面的现代简约空间效果图、材质软装搭配板，沙发置入效果，最好有一位女性在客厅使用沙发的真实生活感。暖白原木色调。

**附件：** 空间/沙发 product 图

| 检查项 | 预期 |
|--------|------|
| QA | **无白底** 仍可继续（室内放宽） |
| shot | 空间效果图、材质板、产品置入/人物场景 |
| **不应出现** | 包装类 shot |
| 人感 | 至少 1 张含人物生活场景 |

## 四、分阶段 UAT（按规格 Phase）

### Phase 1 — 识图准入（UAT-P1）

| UAT-ID | 场景 | 操作 | Pass 标准 |
|--------|------|------|-----------|
| UAT-P1-001 | 清晰 product 图 | 正常上传 + 包装需求 | QA **通过或静默**进入方案；侧栏可见识图相关说明 |
| UAT-P1-002 | 模糊/杂底图 | 故意上传非白底模糊图 | 出现 QA 门控；选项含 **重拍** / **生成白底图** |
| UAT-P1-003 | 选「生成白底图」 | 点击后继续 | 后续仍按 **原 utterance 意图** 出包装/电商，**不**变成「只出白底」 |
| UAT-P1-004 | 选「我重新拍摄上传」 | 点击后 | 方案/画布 SSOT **清空**；可重新上传再走 |
| UAT-P1-005 | lazy seed | CVS-02 全程观察 | **先** 有 SSOT 方案节点，**后** 出现白底/四视图出图 |

---

### Phase 2 — 对话框方案 + 宏观选择 + SSOT（UAT-P2）

| UAT-ID | 场景 | Pass 标准 |
|--------|------|-----------|
| UAT-P2-001 | 方案初稿 | 侧栏 **长文 prose** ≥ 约 200 字；读起来像 **行业方案**，不是 prompt 列表 |
| UAT-P2-002 | 草案不落画布 | 从发话到宏观确认前，画布 **无** 方案文本节点 |
| UAT-P2-003 | 单套方案 | 仅 1 套时 **不出现** 选择卡片，直接进入 SSOT |
| UAT-P2-004 | 多套方案 | ≥2 套卡片；**推荐** 标醒目 + **理由** 一句话可读 |
| UAT-P2-005 | SSOT | 确认后画布 **1 个方案节点**；内容与所选一致 |
| UAT-P2-006 | 编辑 SSOT | 用户在画布改方案文字 → 提供「重新拆解」或等价提示 | 
| UAT-P2-007 | 修订方案 | 对话「方案改成更简约」≤3 次 | 重新出 prose + 卡片；旧 SSOT 被替换 |
| UAT-P2-008 | 修订超限 | 第 4 次仍要改 | 提示超限；按 **推荐方案** 继续 |

---

### Phase 3 — 拆解 / 确认 / 出图（UAT-P3）

| UAT-ID | 场景 | Pass 标准 |
|--------|------|-----------|
| UAT-P3-001 | shot 清单 | 确认出图前可见 **shot 表**（场景名、类型、所属宏观方案） |
| UAT-P3-002 | 删减 shot | 对话「不要结构示意」 | 更新清单后 **不再** 出该图 |
| UAT-P3-003 | 拓扑门控 | 展示拓扑；点「确认出图」后才开始 | 
| UAT-P3-004 | 并行出图 | 多 shot 同时「出图中」 | 
| UAT-P3-005 | 部分失败 | 模拟上游超时 | 弹窗「部分出图未完成」；可选 **确认已完成** |
| UAT-P3-006 | 与手工一致 | 同图同话术：Agent SSOT prose **体裁** 与手工点「生成方案」相近 | 主观 ✓/✗ + 备注 |

---

### Phase 4 — 定稿交付（UAT-P4）

| UAT-ID | 场景 | Pass 标准 |
|--------|------|-----------|
| UAT-P4-001 | 分组 | 定稿 UI 按 **场景/shot** 分组（可 rollup 类型标题） |
| UAT-P4-002 | 切换候选 | 同 shot 多候选切换 | **不** 触发重新生成 |
| UAT-P4-003 | 微调重绘 | 点某 shot「微调重绘」 | **仅该 shot** 重出 |
| UAT-P4-004 | 确认定稿 | 「确认全部定稿」 | 任务结束；画布保留定稿图 |
| UAT-P4-005 | 每场景 1 张 | 交付后 | 每个 shot **exactly 1** 张定稿 |

## 五、负向与边界 UAT（用户视角）

| UAT-ID | 场景 | 操作 | Pass 标准 |
|--------|------|------|-----------|
| UAT-NEG-001 | 无附件 | 只发包装话术 | 明确提示需产品图；**不** 静默胡出 |
| UAT-NEG-002 | 资产库无 role | 资产库选图未标 product | 仍应识图或提示绑定 product；**不** 只出 1 类白底 |
| UAT-NEG-003 | demo 画布 | 新建未落库即发消息 | **不应** 出现（应修复为禁用或自动 create session） |
| UAT-NEG-004 | 切标签 | 出图中断言切走 | 回来后可继续或明确失败提示 |
| UAT-NEG-005 | 多选第 3 套宏观 | 勾 A+B+C | UI 阻止或提示 **最多 2 套** |
| UAT-NEG-006 | 中止 | 中途「重新拍」 | 方案节点、出图节点、附件 **清空** |

## 六、与手工画布对齐验收（UAT-MANUAL）

**目的：** 验证 Agent 路径与 **用户手工** 路径体验一致。

| 步骤 | 手工路径 | Agent 路径 | 对齐点 |
|------|----------|------------|--------|
| 1 | 新建文本节点 + 挂 product 图 | 侧栏附件 I1 | 同一张 product ref |
| 2 | 输入同一句 CVS-02 话术 | 同话术 | |
| 3 | 点节点「生成方案」 | 等 Agent 2a prose | **体裁** 均为行业方案长文 |
| 4 | 用户自己复制方案到节点 | Agent 2c SSOT 节点 | 均为 **可读 prose** |
| 5 | 手工建 shot 文本 + 连线出图 | Agent 自动拆解+编排 | Agent 省步骤，但 **shot 语义** 应覆盖用户会写的构图 |

**UAT-MANUAL-001 Pass：** 产品评审认为 Agent SSOT 与手工生成方案 **同一类文档**（可编辑、有行业细节，非 JSON）。
