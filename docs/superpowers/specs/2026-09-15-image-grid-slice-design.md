# 图片节点宫格裁剪（Grid Slice）设计

日期：2026-09-15  
状态：Draft（待产品确认后进入 implementation plan）  
相关：Wave A 浮层二次操作 IA；放大落子模式；精修工作台壳；Agent 侧栏编排（P1）

## 1. 背景与目标

创作者常拿到「一张多格设定/电商九宫格/分镜板」，需要拆成多张独立图再分别精修、作参考或接下游视频。竞品在节点顶栏提供「宫格裁剪」；lnkpi 已有放大（派生子节点）、精修（同壳工作台）、下载，但**无像素级宫格切分**。

**目标（P0）**

- 在图片节点上把整图**均分**切成多张独立图，落到画布新节点，服务分镜/设定/电商九宫格拆格。
- 入口贴近竞品：节点顶栏「宫格裁剪 ▾」。
- 自定义工作台：**精修同壳、宫格专房**（体感像进精修房间，实现上独立会话）。

**非目标（P0）**

- 拖辅助线不等分、点选部分格、涂黑保留原尺寸。
- 专用打包下载（沿用现有多选下载）。
- Nest 切图 API / Agent tool 的完整实现（契约预留，见 §6）。

## 2. 用户与场景

| 场景 | 说明 |
|------|------|
| 分镜拆格 | 一张分镜板 → N 格独立图 → 分别填词或接视频 |
| 设定/表情拆格 | 角色表、表情九宫格拆开单用 |
| 电商九宫格 | 实拍生成九宫格整图后拆开（人机 P0；Agent 闭环见 P1） |

**成功标准**

- 3×3 一键切：源不变、9 子节点 + 边、可继续编排。
- 「自定义…」工作台壳与精修一致，无精修工具污染。
- 失败不留下半成品节点。

## 3. 产品决策摘要

| 项 | 决策 |
|----|------|
| 输出 | 独立图片 → 画布新节点为主；下载不进主路径 |
| 网格 | 预设 + 自定义行列（均分）；不等分 P1+ |
| 入口 | 节点顶栏「宫格裁剪 ▾」（竞品位） |
| 下拉 | `2×2…7×7` 一键切；「自定义…」进工作台 |
| 工作台 | 大工作台；**视觉/左右比例/侧栏 dock 对齐精修**；独立 `gridSlice` 会话 |
| 切图实现 P0 | 前端 Canvas 切图 → 现有 `persistMediaUrl` → 落子 |
| 与放大 | 同源策略：源不变、子节点 + 边 |
| 与精修 | 互斥；壳可复用样式与 layout token，不复用 mask 状态机 |
| Agent | P1：后端 slice + tool，契约与 P0 对齐（§6） |

## 4. 信息架构与入口

### 4.1 显示条件

- 单选 `type === 'image'` 且存在可用 `data.url`。
- 生成中 / 无 url：禁用并 `title` 说明。
- `refine` 会话打开时：禁用宫格入口（或提示先退出）；宫格工作台打开时反之。

### 4.2 顶栏下拉

```
宫格裁剪 ▾
  2×2 … 7×7     → 立即均分切并落子
  自定义…       → 打开宫格工作台（默认 3×3 预览）
```

文案对外统一 **「宫格裁剪」**；内部能力名 `gridSlice`。

### 4.3 顶栏挂载（相对现有 IA）

- 竞品位是**贴在选中图片节点上方的工具条**（非整页 Header）。实现上可扩展现有选中态 chrome（与 `SelectionActionBar` 同层或合并为「节点操作条」），保证视觉上落在节点顶缘，而非仅画布角落的通用浮层。
- Wave A 已将「放大 / 编辑」放在选中浮层；本特性按产品决策**额外**在节点顶栏暴露「宫格裁剪」，二者可并存：放大/编辑保持原入口，宫格用顶栏下拉（更贴竞品与分镜心智）。
- 精修打开时整条节点操作条按现有规则隐藏（与放大入口一致）。

### 4.4 一键切反馈

- 进行中：入口禁用，轻量 loading。
- 成功：toast「已裁剪为 N 张」；建议选中新节点集合。
- 失败：toast 原因，画布无新节点。

## 5. UI/UX：精修同壳 · 宫格专房

### 5.1 原则

用户感知：进入与精修同类的沉浸工作台（左工作区 + 右 docked 侧栏、宽度量级、折叠、窄屏策略一致）。  
实现：独立房间，**不出现**画笔/蒙版/对照/版本条。

### 5.2 布局

| 区域 | 行为 |
|------|------|
| 左 `GridSliceWorkViewport` | 原图 contain 居中；均分网格线；格内序号 1…N；底栏「共 N 格」 |
| 右 `GridSliceSidePanel` | 默认 docked；宽度与精修面板同量级（可复用 clamp）；可折叠为细条 |
| 窄屏 | 与精修一致：侧栏改底栏/抽屉 |

P0 可不做精修的「浮动窗口」；若壳上该控件显眼，则隐藏或禁用，避免半套交互。

### 5.3 侧栏控件

- 标题：宫格裁剪 · `W × H px`
- 均分预设：2×2 … 7×7
- 列 / 行数字输入（1–7）+「应用划分」
- 状态：当前 `R × C = N` 格
- 主按钮：「裁剪 N 张」；次：「取消」/ × / Esc

P0 不做：自由裁剪 Tab、加线/拖线、格多选、涂黑模式。

### 5.4 视觉

深色 neo 画布语境；侧栏/按钮跟精修 chrome 一致；网格线与序号清晰可读；主 CTA 用现有强调色。不做竞品式拖动手柄（不等分未做）。

## 6. 能力契约与数据流

### 6.1 能力契约（人机与 Agent 共用语义）

```ts
// 逻辑契约（非最终代码签名）
input: {
  sourceUrl: string
  cols: number  // 1..7
  rows: number  // 1..7
  // P1 Agent 可选：targetCanvasId, placeNodes: boolean, connectFromSourceId?: string
}
output: {
  urls: string[]           // 行主序，长度 = cols * rows
  // 若 placeNodes：nodeIds[], edgeIds[]
}
```

子节点建议写入追溯字段：

```ts
data.gridSlice?: {
  sourceNodeId: string
  index: number       // 0-based，行主序
  cols: number
  rows: number
}
```

`label` 建议：`{源 label} · 格{index+1}`。

### 6.2 P0 数据流（前端）

```
url → decode → equalRectangles(cols,rows) → canvas export blobs
  → persistMediaUrl × N（全成功）
  → addNode × N + addEdge(source→child)
  → layoutNodesInGrid(children)
```

- 像素：整数格；末行/末列吸收余数，无缝无丢边。
- 上限：cols/rows ∈ [1,7]，N ≤ 49；边长过大或解码失败则拒绝。
- 落子事务：先切齐并 persist 全部成功，再批量改画布；失败不留孤儿节点。
- 积分：P0 本地后处理，不扣生成积分；未登录 persist 策略与现有上传/放大一致。

### 6.3 P1：后端切分与 Agent（必做扩展，非 P0 实现）

**动机**：侧栏 Agent 编排示例——芯片上传实拍 → 生成电商九宫格整图 → **切 9 张** → 分别连视频节点填营销提示词。Agent 无法依赖浏览器 Canvas，必须调用服务端能力。

**P1 交付**

- `POST /studio/image/slice`（或等价）：服务端 sharp（或现有图片管线）按契约切图并持久化，返回 `urls[]`。
- Agent tool（如 `grid_slice_image`）：入参契约同上；可选 `applyCanvasActions` 落子 + 边 + grid 布局。
- 人机「自定义工作台 / 一键切」可逐步改为调同一 API（或保留前端快路径），**对外语义不变**。

P0 spec 必须冻结 §6.1，避免日后两套行列/排序语义。

## 7. 与现有模块关系

| 模块 | 关系 |
|------|------|
| 放大 `useImageUpscale` / `handleUpscaleForNode` | 复用「源不变 + 子节点 + 边 + 放置」模式 |
| 精修 refine | 互斥会话；复用壳/layout/inset，不复用工具状态 |
| Image Dock | 不增加主入口（保持干净） |
| 下载 / 打包 | 不新做；多选子节点走现有能力 |
| `layoutNodesInGrid` | 子节点排布 |
| Wave A backlog「宫格」 | 本特性落地该项 |

## 8. 错误与边界

| 情况 | 体验 |
|------|------|
| 无 url / 生成中 | 入口禁用 |
| CORS / 解码失败 | toast，不落子 |
| 超限行列或过大图 | toast 说明上限 |
| persist 部分失败 | 整次失败，无孤儿节点 |
| 与精修同时 | 后开者禁用并提示 |

## 9. 验收

**手工**

- [ ] 顶栏下拉 3×3：9 子节点 + 边，源 url 不变  
- [ ] 自定义工作台：精修同壳；无 mask/版本 UI；改 2×4 预览与落子正确  
- [ ] 精修打开时宫格禁用；宫格打开时精修不可并行  
- [ ] 失败路径无半成品节点  
- [ ] 多选子节点可用现有下载  

**自动化（实现阶段）**

- 均分矩形（含余数）单测  
- 行列 clamp  
- 编排：persist 全成功才 addNode
