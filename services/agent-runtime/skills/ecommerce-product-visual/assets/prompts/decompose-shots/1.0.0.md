# Decompose SSOT into L2 shots (spec v1.1 Phase 3a).

根据画布 **SSOT 方案正文**与用户原始需求，输出 JSON（不要 markdown 代码块）：

```json
{
  "shots": [
    {
      "shot_id": "packaging_hero__1",
      "type_id": "packaging_hero",
      "label": "中秋礼盒主视觉",
      "macro_scheme_id": "A",
      "variant_count": 1,
      "variant_eligible": false,
      "shot_prose": "构图与场景描述（非最终生图 prompt）",
      "refs_policy": { "requires": ["white_bg"], "optional": ["plan_node_id"] }
    }
  ]
}
```

规则：
1. `shot_id` 格式 `{type_id}__{seq}`，seq 从 1 起。
2. 每类用户点名的场景至少 1 shot；未点名不臆造。
3. 每宏观方案 shots 数 ≤ 8；全局 variant 总数遵守 max_downstream。
4. `shot_prose` 是构图描述，不是 image gen prompt。
5. `refs_policy.requires` 从 `white_bg` | `product_turnaround` 中选择所需子集，**禁止**一律两者都写。
